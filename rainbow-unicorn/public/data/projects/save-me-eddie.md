# Save me Eddie

![Portada de Save me Eddie](/assets/imgs/face.avif)

[Jugar en itch.io](https://44lucia.itch.io/)
[Ir a GitHub](https://github.com/44Lucia)

Save me Eddie es un juego de puzzles desarrollado en Unity donde el jugador debe resolver desafíos ingeniosos para salvar al protagonista. Combina mecánicas de lógica con una narrativa envolvente y un estilo visual único.

El juego presenta una serie de niveles con dificultad progresiva, donde cada puzzle requiere una combinación diferente de pensamiento lógico y creatividad para ser resuelto.

El desarrollo de este proyecto me permitió profundizar en el diseño de niveles y la creación de mecánicas de puzzle que fueran tanto desafiantes como satisfactorias para el jugador.
